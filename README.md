## 💻 Featured Projects

### 📈 Algorithm Visualizer
`React` · `Vite` · `JavaScript` · `CSS`

Interactive app that animates 11 sorting, searching, and graph algorithms step by step, with adjustable speed and input size. Algorithms are written as generator functions, so rendering stays separate from logic and playback can pause and step. A live counter shows comparisons and swaps per run.

[Live Demo](https://github.com/khushib-20) · [Source](https://github.com/khushib-20)

### 🧠 Tic-Tac-Toe AI Engine
`Python` · `Minimax` · `Alpha-Beta Pruning` · `OOP`

An unbeatable AI that searches all 255,168 possible games. It was checked across all 5,478 legal positions with zero losses, and it picks a move in under 2 ms. [Source](https://github.com/khushib-20/tic_tac_toe)

### 📊 Customer Churn Prediction System
`Python` · `Scikit-Learn` · `Pandas` · `SMOTE`

An ML pipeline on 7,000+ customer records. SMOTE corrected a 74/26 class imbalance and raised churner recall from 52% to 86%. The Random Forest model reaches 82% accuracy under 5-fold cross-validation.
